Lição 2 — Would, Could e Condicionais

Prática dinâmica e interativa para o Wender

Foco: Modal Verbs & Conditionals
💡 Esta lição é 100% interativa: clique nas opções, complete as frases e vire as cartas. Seu progresso é mostrado na barra abaixo.
Pontuação: 0 / 120% concluído

📘 Regras rápidas

WOULD → hipóteses / educação
I would help you if I had time. / Would you like some coffee?
COULD → habilidade passada / possibilidade / sugestão
She could swim when she was five. / We could go to the beach.
First Conditional: If + present, will + verb
If it rains, I will stay home.
Second Conditional: If + past, would + verb
If I won the lottery, I would travel the world.

🎯 Exercício 1: Escolha a resposta certa

2. ___ you help me with this exercise, please?
3. If she studies hard, she ___ pass the exam.
4. When I was a kid, I ___ climb trees really fast.

🎭 Exercício 4: Simulação (Roleplay)

Cenário: Pedindo um favor no trabalho
Wender pede a um colega para trocar de turno. Use "Could you..." e "Would you mind..." na conversa.
Cenário: Planejando as férias dos sonhos
Descreva o que você faria se pudesse tirar 3 meses de férias. Use "If I had... I would...".
Cenário: Dando conselhos a um amigo
Um amigo perdeu o emprego. Dê conselhos usando "If I were you, I would...".
